Hello! This is a retro-designed website inspired by classic online games that I was fond of during my childhood, it features simple pixel art aesthetics, neon colors, and interactive elements.

## Features

- **Retro Theme**: Custom CSS properties 
- **Pixelated Design**: Utilizes pixel fonts and retro elements
- **Responsive Layout**: Adapts to desktop, tablet, and mobile viewports
- **Shared Navigation**: Consistent header across all pages
- **Interactive Components**: Animated buttons, skill bars, and form elements

## Pages

1. **index.html** - Home/Landing page 
2. **about.html** - About page featuring player profile, skills stats, and experience timeline over the past college years
3. **contact.html** - Contact page with feedback form and social media channels

## Design System (style.css)

### Colors Used
- `--bg-dark`: #0a0a0a (background)
- `--bg-darker`: #050505 (darker background)
- `--bg-card`: #1a1a1a (card surfaces)
- `--accent-primary`: #8a2be2 (violet/purple)
- `--accent-secondary`: #9400d3 (dark violet)
- `--accent-neon`: #39ff14 (neon green)
- `--text-primary`: #ffffff (primary text)
- `--text-neon`: #39ff14 (neon highlights)

### Component Classes
- `.btn-pixel`:  Button with hover/active states
- `.card-panel`: Dialogue-box style panel
- `.skill-bar` / `.skill-bar-fill`: Progress bars
- `.pixel-tag`: Pixel-style tags 
- `.form-group` / `.pixel-input`: Styled form elements
- `.header-bar`: Shared navigation header
- `.status-badge`: Availability status indicator

## Responsive Breakpoints
- Desktop: ~1440px 
- Tablet: ~768px
- Mobile: ~390px 

## Usage
Simply open `index.html` in any modern web browser to view the portfolio. The site uses only HTML and CSS - no JavaScript required for basic functionality.
